# 🎓 Pro Tutor Platform Template (Коммерческий шаблон платформы репетитора)

Готовый, протестированный в боевых условиях шаблон интерактивной платформы для репетиторов, частных преподавателей и образовательных студий.

В отличие от стандартных плоских визиток на Tilda или Taplink, данный шаблон представляет собой **интерактивную сервисную платформу** с геймификацией, диагностикой знаний и встроенным кабинетом преподавателя.

---

## 🚀 Ключевые продающие фичи (Value Proposition)

1. **Apple-Style Minimalist Bar & 4 темы оформления**:
   - Минималистичная капсула `[ 🎨 Саян ▾ ]` в шапке открывает выпадающее меню из матового стекла (`backdrop-blur-2xl`) с галочками активного выбора.
   - Щедрые отступы (>180px–330px gap), исключающие заезжания и обрезания текста на любых экранах (от мобильных до 4K).
   - Звуковой движок Web Audio API для тактильного отклика при кликах.

2. **Интерактивная примерочная фото («Примерка фото»)**:
   - Клиент или преподаватель может прямо в браузере примерить разные образы или загрузить своё реальное фото.
   - Выбранное фото сохраняется в `localStorage` и отображается при повторных визитах.

3. **Экспресс-диагностика за 20 секунд (Квиз «Какой ты супергерой»)**:
   - 3 наглядных вопроса для выявления страхов (геометрия, вычислительные ошибки, нехватка времени).
   - Расчёт архетипа ученика и персонализированная рекомендация.
   - Кнопка по результату квиза автоматически скроллит к бронированию и предзаполняет нужный формат подготовки.

4. **«Тетрадка преподавателя» (Cloud Sync через Supabase + Кабинет по PIN)**:
   - **Облачная синхронизация (`ngsonqwylcwcziwxurkc`)**: данные загружаются из Supabase (`client_sites` с конфигом программ/текстов в `config`, `client_bookings`, `client_reviews`) в мульти-тенантной схеме по `site.slug`.
   - **Для учеников**: выбор свободных слотов через RPC `create_public_booking_v2` (с advisory lock на день и проверкой пересечений интервалов), интеграция с Яндекс.Календарём и скачивание `.ICS` файла.
   - **Для преподавателя**: скрытый вход в футере — **серверная проверка bcrypt PIN** через `private.client_site_secrets` (без хранения PIN-кода в HTML; для новых сайтов по умолчанию задаётся `1234` в БД и меняется прямо в кабинете).
   - **3-вкладочный конструктор-кабинет (Constructor v3)**:
     1. *Слоты и записи*: блокировка/разблокировка окон (`admin_set_slot_state_v2`, `admin_bulk_day_action_v2`), недельный график `Пн–Вс`, список записавшихся учеников и ручное добавление уроков.
     2. *Тексты, цены и ссылки*: выбор темы оформления по умолчанию (`cozy-cat`, `sakura`, `artek`, `cyber`), конструктор форматов (скрытие/показ с защитой `>=1` активного тарифа и добавление кастомных программ), автосинхронизация телефона и ссылок **МАКС / Telegram** при вводе, настройка `avitoUrl` и `reviewsChannelUrl` («Канал отзывов ТГ/МАКС»).
     3. *Отзывы и PIN*: компактная подсказка из 3 шагов, ручное добавление отзывов с **Live-предпросмотром** (`admin_add_review`), публикация/скрытие (`admin_set_review_visibility`), удаление в архив (`admin_delete_review`) и смена PIN-кода (`admin_change_pin`).

5. **Бесшовная связь в 1 тап**:
   - Прямой контакт в **МАКС** с пульсирующим бейджем онлайна.
   - Прямой чат в **Telegram** с уже сформированным предзаполненным сообщением (имя, класс, дата, время, формат).
   - Прямой звонок по телефону, ссылка на профиль **Авито** (`contacts.avitoUrl`) и кнопка канала отзывов (`contacts.reviewsChannelUrl`) в шапке отзывов и подвале сайта.

6. **Уроки реального продакшена и конверсионные блоки v2**:
   - **Контрастный первый экран**: жёсткий scrim + `.photo-overlay-light` гарантируют яркий белый текст поверх фото в светлых и тёмных темах.
   - **Блоки доверия**: «Почему выбирают меня?», интерактивные вкладки «Как проходят занятия» («План урока / Конспект / Онлайн-доска»), «Результаты учеников».
   - **Параллельный формат (2 ученика)**: подробное объяснение отдельных досок, 10-минутных циклов и развития самостоятельности без учителя «над душой».
   - **Честные отзывы**: форма 1–5★ с сохранением в Supabase (`create_public_review`) + кнопка пересылки копии отзыва преподавателю в Telegram / МАКС и модерация в Тетрадке преподавателя.
   - **Независимый деплой**: каждый заказчик получает свой собственный репозиторий и отдельный домен/URL без объединения в общий каталог.
   - **0px мобильный оверфлоу и локальная таймзона**: проверено тестами от 360px до 1440px, даты формируются через `toLocalIso()` без смещения UTC.

## ⚡ Быстрый старт (генерация сайта за 5 секунд)

### 1. Скопируйте и заполните конфиг клиента
Скопируйте `config.example.json` в `client.json` и укажите данные преподавателя и `site.slug` (для синхронизации с Supabase):
```json
{
  "site": {
    "slug": "ivan-physics"
  },
  "teacher": {
    "name": "Иван Петров",
    "subject": "Физика и математика",
    "subtitle": "Эксперт ЕГЭ • Высшая категория",
    "targetAudience": "9–11 классы • ЕГЭ и ОГЭ"
  },
  "contacts": {
    "phone": "+7 999 123 45 67",
    "maxUrl": "https://max.ru/u/+79991234567",
    "telegramHandle": "@ivan_physics",
    "telegramUrl": "https://t.me/ivan_physics",
    "avitoUrl": "https://www.avito.ru/...",
    "reviewsChannelUrl": "https://t.me/ivan_reviews"
  },
  "theme": {
    "default": "cozy-cat"
  },
  "admin": {
    "pinCode": "1234"
  }
}
```
> Примечание: поля `site.supabaseUrl`, `site.supabaseKey`, `contacts.reviewsChannelUrl` и `theme.default` опциональны — по умолчанию `generate.py` подставляет проект `ngsonqwylcwcziwxurkc` и тему `cozy-cat`. Поле `admin.pinCode` нужно для валидации конфига `generate.py`, но сам PIN-код в HTML не зашивается и проверяется на стороне Supabase (`private.client_site_secrets`).

### 2. Запустите генератор
```bash
python generate.py --config client.json --output dist/index.html
```

Готовый файл `dist/index.html` полностью автономен (не требует сборщиков, Node.js или отдельного бэкенда; статические изображения берутся из папки `assets/` конкретного клиентского репозитория) и готов к загрузке на хостинг.

## 🌐 Деплой в прод

### Вариант А: GitHub Pages (0 ₽ в месяц)
1. Создайте репозиторий на GitHub.
2. Положите сгенерированный `index.html` в корень.
3. В настройках репозитория: `Settings -> Pages -> Branch: master -> / (root) -> Save`.
4. Через 30 секунд сайт доступен на `https://<username>.github.io/<repo>/`.

### Вариант Б: Vercel / Netlify
1. Перетащите папку `dist` в дашборд Vercel или Netlify.
2. Сайт публикуется за 10 секунд с бесплатным SSL-сертификатом.

## 💼 Чек-лист для онбординга реального заказчика

Когда берёте заказ от репетитора, запросите у него:
1. **ФИО и предмет** (например: «Елена Смирнова, Английский язык для школьников и ОГЭ»).
2. **Контакты**: номер телефона, ссылка на МАКС, юзернейм Telegram.
3. **Фотографии**: 1–4 фото для портретной зоны и фото-примерочной.
4. **Программы и цены**: 2–3 тарифа (название, длительность, цена за урок).
5. **Целевая аудитория**: классы (например, 8–9 класс или 10–11 класс).
6. **Желаемый PIN-код** для входа в Тетрадку преподавателя.

Заполняете эти данные в JSON-конфиг, запускаете скрипт — сайт готов к передаче заказчику.
Рекомендуемый чек для продажи такого решения: **40 000 – 75 000 ₽** под ключ.
