# 🎓 Pro Tutor Platform Template (Коммерческий шаблон платформы репетитора)

Готовый, протестированный в боевых условиях шаблон интерактивной платформы для репетиторов, частных преподавателей и образовательных студий.

В отличие от стандартных плоских визиток на Tilda или Taplink, данный шаблон представляет собой **интерактивную сервисную платформу** с геймификацией, диагностикой знаний и встроенным кабинетом преподавателя.

---

## 🚀 Ключевые продающие фичи (Value Proposition)

1. **Apple-Style Minimalist Bar & 4 темы оформления**:
   - Минималистичная капсула `[ 🎨 Саян ▾ ]` в шапке открывает выпадающее меню из матового стекла (`backdrop-blur-2xl`) с галочками активного выбора.
   - Щедрые отступы (>180px–330px gap), исключающие заезжания и обрезания текста на любых экранах (от мобильных до 4K).
   - Звуковой движок Web Audio API для тактильного отклика при кликах.

2. **Интерактивная примерочная фото («Примерка фото»)**:
   - Клиент или преподаватель может прямо в браузере примерить разные образы или загрузить своё реальное фото.
   - Выбранное фото сохраняется в `localStorage` и отображается при повторных визитах.

3. **Экспресс-диагностика за 20 секунд (Квиз «Какой ты супергерой»)**:
   - 3 наглядных вопроса для выявления страхов (геометрия, вычислительные ошибки, нехватка времени).
   - Расчёт архетипа ученика и персонализированная рекомендация.
   - Кнопка по результату квиза автоматически скроллит к бронированию и предзаполняет нужный формат подготовки.

4. **«Тетрадка преподавателя» (Интерактивное расписание + Кабинет по PIN)**:
   - **Для учеников**: выбор свободных слотов, интеграция с Яндекс.Календарём и скачивание `.ICS` файла.
   - **Для преподавателя**: скрытый вход по PIN-коду (по умолчанию `1234`) в футере.
   - Режим управления: блокировка/разблокировка окон в 1 клик, список записавшихся учеников, ручное добавление уроков, экспорт базы в JSON.

5. **Бесшовная связь в 1 тап**:
   - Прямой контакт в **МАКС** с пульсирующим бейджем онлайна.
   - Прямой чат в **Telegram** с уже сформированным предзаполненным сообщением (имя, класс, дата, время, формат).
   - Прямой звонок по телефону.

6. **0px мобильный оверфлоу и доступность WCAG AA**:
   - Проверено тестами на экранах 360px, 375px, 393px, 412px, 768px, 1024px, 1280px, 1440px.

## ⚡ Быстрый старт (генерация сайта за 5 секунд)

### 1. Скопируйте и заполните конфиг клиента
Скопируйте `config.example.json` в `client.json` и укажите данные преподавателя:
```json
{
  "teacher": {
    "name": "Иван Петров",
    "subject": "Физика и математика",
    "subtitle": "Эксперт ЕГЭ • Высшая категория",
    "targetAudience": "9–11 классы • ЕГЭ и ОГЭ"
  },
  "contacts": {
    "phone": "+7 999 123 45 67",
    "maxUrl": "https://max.ru/u/+79991234567",
    "telegramHandle": "@ivan_physics",
    "telegramUrl": "https://t.me/ivan_physics"
  },
  "admin": {
    "pinCode": "5678"
  }
}
```

### 2. Запустите генератор
```bash
python generate.py --config client.json --output dist/index.html
```

Готовый файл `dist/index.html` полностью автономен (не требует сборщиков, Node.js или бэкенда) и готов к загрузке на хостинг.

## 🌐 Деплой в прод

### Вариант А: GitHub Pages (0 ₽ в месяц)
1. Создайте репозиторий на GitHub.
2. Положите сгенерированный `index.html` в корень.
3. В настройках репозитория: `Settings -> Pages -> Branch: master -> / (root) -> Save`.
4. Через 30 секунд сайт доступен на `https://<username>.github.io/<repo>/`.

### Вариант Б: Vercel / Netlify
1. Перетащите папку `dist` в дашборд Vercel или Netlify.
2. Сайт публикуется за 10 секунд с бесплатным SSL-сертификатом.

## 💼 Чек-лист для онбординга реального заказчика

Когда берёте заказ от репетитора, запросите у него:
1. **ФИО и предмет** (например: «Елена Смирнова, Английский язык для школьников и ОГЭ»).
2. **Контакты**: номер телефона, ссылка на МАКС, юзернейм Telegram.
3. **Фотографии**: 1–4 фото для портретной зоны и фото-примерочной.
4. **Программы и цены**: 2–3 тарифа (название, длительность, цена за урок).
5. **Целевая аудитория**: классы (например, 8–9 класс или 10–11 класс).
6. **Желаемый PIN-код** для входа в Тетрадку преподавателя.

Заполняете эти данные в JSON-конфиг, запускаете скрипт — сайт готов к передаче заказчику.
Рекомендуемый чек для продажи такого решения: **40 000 – 75 000 ₽** под ключ.
